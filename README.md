# FinLite

<p align="justify">
  <strong>Sistema de gestão financeira desenvolvido para auxiliar pequenos empreendedores no controle das finanças do negócio.</strong>
</p>

<p align="justify">
O projeto foi criado a partir da identificação de dificuldades enfrentadas por microempreendedores que realizam controles financeiros de forma manual, utilizando cadernos e anotações físicas.
<p> Nosso objetivo foi desenvolver uma solução simples, intuitiva e acessível para organizar vendas, estoque e informações financeiras em um único sistema. </p>
